# 露露王国助手（实时盘面 + 自动下注）

针对《露露王国》三款小游戏（星海逃杀 / 斗鸡 / 赛马）的多用户辅助面板：

- **实时盘面**：WebSocket 全局采集三个游戏的回合状态、各房间投注额与人数，页面实时刷新
- **自动下注**：每用户独立的下注引擎，可配置策略 / 单注金额 / 止损，支持止盈止损与每日亏损保护
- **盈亏统计**：按游戏官方口径统计今日 / 累计盈亏，含下注历史记录
- **其他**：余额查询、仓库收取（harvest）、20:00–21:00 地狱时段自动禁注

## 技术栈

Python 3 + Flask（waitress 部署）+ websocket-client + pycryptodome，前端为单文件 HTML（ECharts CDN）。

## 快速开始

```bash
pip install -r requirements.txt
python server_app.py
```

浏览器打开 `http://127.0.0.1:18080`：

1. 注册一个面板账号
2. 在设置里通过「发验证码 → 登录」绑定游戏账号（Token 全局共用）
3. 配置策略和金额，开启下注引擎

## 配置

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `LULU_PORT` | `18080` | 服务端口 |
| `LULU_SECRET` | 自动生成 | Flask session 密钥（缺省写入 `data/secret.key` 复用） |

运行数据（SQLite 数据库、回合记录等）全部落在 `data/` 目录，首次启动自动创建。
